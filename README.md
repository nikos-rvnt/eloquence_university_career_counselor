# eloquence_university_career_counselor

This repo includes the English and the Italian version of the CNR pilot application of the Eloquence project, that is, a University Career Counselor system.  


The user is firstly asked to introduced themself and give essential information regarding their educational background, their field of interest, their career goal, the region of residency, whether are willing to relocate. Once, these info are collected 8 RIASEC questions are asked to the user in order to extract their personality profile. Each question needs to be answered in a Likert Scale.  
The user profile is complete and a RAG retrieval is performed based on txt files containing informatin about university programms.  
The three most suitable university programms are recommended to the user with an explanation on why each one is suitable for them.
