# eloquence_university_career_counselor

## What this repo includes...
The included python code implementation is the major part of the dialog manager of the CNR Pilot of [ELOQUENCE](https://eloquenceai.eu/) Horizon project. 

The dialog manager acts as a university career counseling dialog system, where the user is asked to answer to questions related to their profile (academic background, name, region, career goal, etc.) and based on their profile the system recommends 3 suitable university programmes.

## How to use it...
Into the ./src directory there is a README file on how to build and run the interactive application in a virtual dockerized environment.
